# OOP_lb3
Реализовать паттерн «Фабрика», реализующую Унаследованный класс 1 и Унаследованный класс 2. (Удалить Класс 1, следовательно реализациию перенести в наследуемые классы)

Унаследованный класс 1: Подсчет количества согласных и гласных в тексте
Унаследованный класс 2: Метод добавления случайных гласных или согласных в случайные места в тексте , для достижения равенства количества гласных и согласных в тексте
